## 6-1　文字列の基礎

### 問1　`s = 'Python'` のとき、次の式の結果を答えなさい。

|   | 式 |   | 式 |
| --- | --- | --- | --- |
| （1） | `s[0]` | （2） | `s[-1]` |
| （3） | `s[1:4]` | （4） | `s[:2]` |
| （5） | `s[::-1]` | （6） | `s[::2]` |
| （7） | `len(s)` | （8） | `s[1:100]` |

#### 解答例

（1）`'P'`　（2）`'n'`　（3）`'yth'`　（4）`'Py'`　（5）`'nohtyP'`　（6）`'Pto'`　（7）`6`　（8）`'ython'`

#### 解説

| 文字 | P | y | t | h | o | n |
| --- | --- | --- | --- | --- | --- | --- |
| 前から | 0 | 1 | 2 | 3 | 4 | 5 |
| 後ろから | -6 | -5 | -4 | -3 | -2 | -1 |

（3）`s[1:4]` は 1 から 4 の手前（3）まで。（8）スライスは範囲がはみ出してもエラーになりません。

---

### 問2　次のプログラムはエラーになります。理由を答えなさい。また（2）は、'Jython' という文字列を作る正しい方法を答えなさい。

**（1）**

```python
s = 'Python'
print(s[6])
```

**（2）**

```python
s = 'Python'
s[0] = 'J'
```

#### 解答例

（1）インデックスは 0〜5 なので、`s[6]` は範囲外（IndexError）。

（2）文字列はイミュータブルなので、1文字だけ書き換えられない（TypeError）。正しくは `s = 'J' + s[1:]`。

#### 解説

文字列を「変える」ときは、新しい文字列を作って変数に代入し直します。

### 問3　次の式の結果（True または False）を答えなさい。

（1）`'abc' < 'abd'`  
（2）`'A' < 'a'`  
（3）`'10' < '9'`  
（4）`'th' in 'Python'`  
（5）`'z' not in 'Python'`  

#### 解答例

（1）True　（2）True　（3）True　（4）True　（5）True

#### 解説

文字列は先頭から1文字ずつ文字コードで比べます（辞書順）。英字は大文字のほうが小さくなります。

（3）数字の文字列は数としてではなく、1文字目の '1' と '9' で比べられます。数として比べるなら `int()` で変換します。

### 問4　次のプログラムの表示を答えなさい。

```python
for i, c in enumerate('abc', 1):
    print(f'{i}番目：{c}')
```

#### 解答例

```text
1番目：a
2番目：b
3番目：c
```

#### 解説

`enumerate(s, 1)` は、番号を 1 から数えて、(番号, 文字) の組を順に取り出します。

## 6-2　文字列の操作

### 問5　`s = 'banana'` のとき、次の式の結果を答えなさい。

（1）`s.find('na')`  
（2）`s.rfind('na')`  
（3）`s.find('x')`  
（4）`s.count('a')`  
（5）`s.replace('a', 'o')`  
（6）`s.upper()`  
（7）`s.startswith('ba')`  

#### 解答例

（1）`2`　（2）`4`　（3）`-1`　（4）`3`　（5）`'bonono'`　（6）`'BANANA'`　（7）`True`

#### 解説

find は見つからないと -1 を返します（index メソッドならエラー）。

（5）（6）元の s は変わらず、新しい文字列が返されます。

### 問6　次のプログラムは「bonono」と表示するつもりですが、「banana」と表示されます。理由を説明し、正しく直しなさい。

```python
s = 'banana'
s.replace('a', 'o')
print(s)
```

#### 解答例

理由：文字列はイミュータブルなので、replace は s を変えずに、置き換えた新しい文字列を返すだけだから。

**直した例（2行目）**

```python
s = s.replace('a', 'o')
```

#### 解説

upper・strip など、文字列を「変える」メソッドはすべて同じです。結果を使うには代入が必要です。

### 問7　次の式の結果を答えなさい。

（1）`'2026/11/17'.split('/')`  
（2）`'a b  c'.split()`  
（3）`'-'.join(['a', 'b', 'c'])`  
（4）`'  abc  '.strip()`  
（5）`'42'.zfill(5)`  

#### 解答例

（1）`['2026', '11', '17']`　（2）`['a', 'b', 'c']`　（3）`'a-b-c'`　（4）`'abc'`　（5）`'00042'`

#### 解説

（2）引数を省略した split は、連続した空白も1つの区切りとみなします。

（3）join は「区切りの文字」のメソッドです。`'-'.join(…)` は「- でつなげる」と読みます。

## 6-3　書式化

### 問8　`n = 42` のとき、次の f文字列の結果を答えなさい。

（1）`f'[{n:>5}]'`  
（2）`f'[{n:<5}]'`  
（3）`f'{n:05}'`  
（4）`f'{n:b}'`  
（5）`f'{0.256:.1%}'`  
（6）`f'{n=}'`  

#### 解答例

（1）`'[   42]'`　（2）`'[42   ]'`　（3）`'00042'`　（4）`'101010'`　（5）`'25.6%'`　（6）`'n=42'`

#### 解説

`>` は右寄せ、`<` は左寄せ、`0` を付けると0埋めです。`b` は2進数、`%` はパーセント表示です。

（6）`{変数=}` は「変数名=値」の形で表示されるので、デバッグに便利です。

## 応用問題（プログラムを作る）

### 問9　回文の判定

入力した文字列が、前から読んでも後ろから読んでも同じ（回文）かどうかを判定するプログラムを作りなさい。

**実行例**

```text
文字列：level
回文です
```

#### 解答例

```python
s = input('文字列：')
if s == s[::-1]:
    print('回文です')
else:
    print('回文ではありません')
```

#### 解説

`s[::-1]` で逆順の文字列が作れます。元の文字列と比べるだけで判定できます。

「しんぶんし」のような日本語でも動きます。

### 問10　1行で2つの整数を入力

スペースで区切って2つの整数を1行で入力し、和・差・積を表示するプログラムを作りなさい。

**実行例**

```text
2つの整数：3 5
和：8　差：-2　積：15
```

#### 解答例

```python
a, b = input('2つの整数：').split()
a = int(a)
b = int(b)
print(f'和：{a + b}　差：{a - b}　積：{a * b}')
```

#### 解説

`split()` で分けた結果をアンパックして、a と b に入れています。

第9章の map を使うと `a, b = map(int, input().split())` と1行で書けます。

### 問11　（発展）文字の種類を数える

入力した文字列に含まれる英字・数字・その他の文字の数を数えて表示するプログラムを作りなさい。

**実行例**

```text
文字列：abc123!?
英字：3　数字：3　その他：2
```

#### 解答例

```python
s = input('文字列：')
alpha = 0
digit = 0
other = 0
for c in s:
    if c.isalpha():
        alpha += 1
    elif c.isdigit():
        digit += 1
    else:
        other += 1
print(f'英字：{alpha}　数字：{digit}　その他：{other}')
```

#### 解説

for文で1文字ずつ取り出し、`isalpha()`・`isdigit()` で種類を調べます。

注意：`isalpha()` は日本語のひらがな・漢字でも True になります。英字だけを数えたいときは `'a' <= c.lower() <= 'z'` のように調べます。

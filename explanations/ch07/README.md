## 7-1　リスト

### 問1　`a = [10, 20, 30, 40, 50]` のとき、次の式の結果を答えなさい。

|   | 式 |   | 式 |
| --- | --- | --- | --- |
| （1） | `a[1]` | （2） | `a[-2]` |
| （3） | `a[1:3]` | （4） | `a[::-1]` |
| （5） | `len(a)` | （6） | `sum(a) / len(a)` |
| （7） | `30 in a` | （8） | `a.index(40)` |

#### 解答例

（1）`20`　（2）`40`　（3）`[20, 30]`　（4）`[50, 40, 30, 20, 10]`　（5）`5`　（6）`30.0`　（7）`True`　（8）`3`

#### 解説

インデックスやスライスの書き方は文字列と同じです。（6）は平均値の求め方です。

### 問2　次のプログラムを順に実行したとき、最後の a の値を答えなさい。

```python
a = [1, 2, 3]
a.append(4)
a.insert(0, 0)
a.pop()
a.remove(2)
print(a)
```

#### 解答例

`[0, 1, 3]`

#### 解説

| 操作 | a の値 |
| --- | --- |
| `a.append(4)` | [1, 2, 3, 4] |
| `a.insert(0, 0)` | [0, 1, 2, 3, 4] |
| `a.pop()` | [0, 1, 2, 3]（末尾の 4 を取り出す） |
| `a.remove(2)` | [0, 1, 3]（値 2 を削除） |

### 問3　次のプログラムの表示を答えなさい。

```python
a = [1, 2]
a.append([3, 4])
print(a)
b = [1, 2]
b.extend([3, 4])
print(b)
```

#### 解答例

```text
[1, 2, [3, 4]]
[1, 2, 3, 4]
```

#### 解説

append はリストごと1つの要素として追加します。複数の要素を追加したいときは extend（または `+=`）を使います。

### 問4　次のプログラムの表示を答えなさい。

```python
a = [1, 2]
b = a
b[0] = 99
c = a.copy()
c[1] = 0
print(a, b, c)
```

#### 解答例

```text
[99, 2] [99, 2] [99, 0]
```

#### 解説

`b = a` は同じリストに名札を追加しただけなので、b を変えると a も変わります。

`a.copy()` は別のリストを作るので、c を変えても a は変わりません。

### 問5　次のプログラムは、並べ替えたリストを表示するつもりですが「None」と表示されます。理由を説明し、2通りの方法で直しなさい。

```python
a = [3, 1, 2]
b = a.sort()
print(b)
```

#### 解答例

理由：`sort()` は a 自体を並べ替えるメソッドで、戻り値は None だから。

**直し方1**

```python
a.sort()
print(a)
```

**直し方2**

```python
b = sorted(a)
print(b)
```

#### 解説

「リスト自体を変えるメソッド（sort・reverse・append など）は None を返す」と覚えておきましょう。

### 問6　`m = [[1, 2, 3], [4, 5, 6]]` のとき、次の式の結果を答えなさい。

（1）`m[1][0]`  
（2）`m[0][2]`  
（3）`len(m)`  
（4）`len(m[0])`  
（5）`m[1]`  

#### 解答例

（1）`4`　（2）`3`　（3）`2`　（4）`3`　（5）`[4, 5, 6]`

#### 解説

`m[行][列]` でアクセスします。`len(m)` は行の数、`len(m[0])` は1行目の要素数（列の数）です。

## 7-2　リスト内包表記

### 問7　次のリスト内包表記の結果を答えなさい。

（1）`[x * 2 for x in range(4)]`  
（2）`[x for x in range(10) if x % 3 == 0]`  
（3）`[len(w) for w in ['a', 'bb', 'ccc']]`  
（4）`[c.upper() for c in 'abc']`  

#### 解答例

（1）`[0, 2, 4, 6]`　（2）`[0, 3, 6, 9]`　（3）`[1, 2, 3]`　（4）`['A', 'B', 'C']`

#### 解説

`[式 for 変数 in イテラブル if 条件]` は、「取り出して → 条件でふるいにかけて → 式で変換して集める」と読みます。

### 問8　次のプログラムの表示を答え、そうなる理由と正しい2次元リストの作り方を答えなさい。

```python
g = [[0] * 2] * 2
g[0][0] = 1
print(g)
```

#### 解答例

表示：`[[1, 0], [1, 0]]`

理由：`[[0] * 2] * 2` は、同じ行のリストを2回並べただけなので、1つを変えると両方が変わって見える。

**正しい作り方**

```python
g = [[0] * 2 for _ in range(2)]
```

#### 解説

内包表記を使うと、行ごとに新しいリストが作られます。

## 応用問題（プログラムを作る）

### 問9　成績処理

点数を次々に入力し、何も入力せずに Enter が押されたら、人数・合計・平均（小数点以下1桁）・最高点・最低点を表示するプログラムを作りなさい。

**実行例**

```text
点数：80
点数：65
点数：90
点数：
人数 3　合計 235　平均 78.3
最高 90　最低 65
```

#### 解答例

```python
scores = []
while True:
    s = input('点数：')
    if s == '':
        break
    scores.append(int(s))
print(f'人数 {len(scores)}　合計 {sum(scores)}　平均 {sum(scores) / len(scores):.1f}')
print(f'最高 {max(scores)}　最低 {min(scores)}')
```

#### 解説

個数がわからないときは「空リスト → append で追加」が定番です。

1つも入力されないと `len(scores)` が 0 になり、割り算でエラーになります。`if scores:` で空かどうかを調べてから計算すると安全です。

### 問10　最大値を自分で求める

スペース区切りで入力した整数の中から、`max()` を使わずに最大値を求めて表示するプログラムを作りなさい。

**実行例**

```text
整数をスペース区切りで：3 7 2 9 4
最大値は9です
```

#### 解答例

```python
nums = [int(x) for x in input('整数をスペース区切りで：').split()]
mx = nums[0]
for x in nums[1:]:
    if x > mx:
        mx = x
print(f'最大値は{mx}です')
```

#### 解説

最初の要素を「仮の最大値」にして、より大きい値が出てきたら入れ替えます。

1行目は、split で分けた文字列を内包表記でまとめて int に変換しています。

### 問11　（発展）平均以上の点数

スペース区切りで点数を入力し、平均点と、平均点以上の点数のリストを表示するプログラムを作りなさい。リスト内包表記を使いなさい。

**実行例**

```text
点数をスペース区切りで：80 65 90 58
平均：73.2
平均以上：[80, 90]
```

#### 解答例

```python
scores = [int(x) for x in input('点数をスペース区切りで：').split()]
avg = sum(scores) / len(scores)
above = [s for s in scores if s >= avg]
print(f'平均：{avg:.1f}')
print(f'平均以上：{above}')
```

#### 解説

平均は先に1回だけ計算しておき、条件付きの内包表記で平均以上のものを集めます。

平均は 73.25 ですが、`:.1f` では 73.2 と表示されます。ちょうど真ん中の値は、近いほうの偶数側に丸められるためです（銀行丸め）。

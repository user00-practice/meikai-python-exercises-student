## 2-1　画面への表示

### 問1　次のプログラムを実行したときの表示を答えなさい。

（1）`print('A', 'B', 'C')`  
（2）`print('A', 'B', 'C', sep='')`  
（3）`print(2026, 11, 17, sep='/')`  
（4）`print(10 + 5, '10 + 5')`  

#### 解答例

**（1）**

```text
A B C
```

**（2）**

```text
ABC
```

**（3）**

```text
2026/11/17
```

**（4）**

```text
15 10 + 5
```

#### 解説

カンマで区切った値は、間にスペースが1つ入って表示されます。`sep=` で区切りの文字を変えられます。

（4）1つ目の `10 + 5` は式なので計算されて `15`、2つ目は ' で囲まれた文字列なのでそのまま表示されます。

---

### 問2　次のプログラムを実行したときの表示を答えなさい。

```python
print('X', end='')
print('Y')
print()
print('1', '2', sep='-', end='!\n')
```

#### 解答例

```text
XY

1-2!
```

#### 解説

`end=''` にすると改行されないので、次の `print('Y')` が同じ行に続きます。

`print()` だけを書くと、空の行（改行だけ）が表示されます。

`sep` と `end` は同時に指定できます。`end='!\n'` は「! を表示して改行」という意味です。

### 問3　次のプログラムはエラーになります。理由を説明し、正しく動くように2通りの方法で直しなさい。

```python
print('合計' + 10)
```

#### 解答例

理由：文字列 `'合計'` と数値 `10` は `+` でつなげられないため（TypeError）。

**直し方の例**

```python
print('合計', 10)
print('合計' + str(10))
```

#### 解説

`+` は、両方が数値なら足し算、両方が文字列なら連結になります。文字列と数値を混ぜると、Python はどちらかわからないためエラーになります。

f文字列を使って `print(f'合計{10}')` と書くこともできます。

## 2-2　キーボードからの読込み

### 問4　次のプログラムで、a に 10、b に 20 を入力したときの表示を答えなさい。

**（1）**

```python
a = input('a：')
b = input('b：')
print(a + b)
```

**（2）**

```python
a = int(input('a：'))
b = int(input('b：'))
print(a + b)
```

#### 解答例

（1）`1020`　（2）`30`

#### 解説

`input()` の結果は、数字を入力しても必ず文字列になります。（1）は文字列どうしの連結なので `'10' + '20'` → `1020` です。

（2）は `int()` で整数に変換してから足しているので、`30` になります。

### 問5　次の式の結果を答えなさい。エラーになる場合は「エラー」と答えなさい。

（1）`int('25') + 5`  
（2）`float('3.5') * 2`  
（3）`str(5) + '個'`  
（4）`int('3.5')`  
（5）`int(' 7 ')`  

#### 解答例

（1）`30`　（2）`7.0`　（3）`'5個'`　（4）エラー（ValueError）　（5）`7`

#### 解説

（4）`int()` は小数の形の文字列を整数に変換できません。小数を読み込むときは `float()` を使います。

（5）前後の空白は無視して変換されます。

### 問6　f文字列を使って、次の表示になる式を書きなさい。

`name = '佐藤'`、`age = 20`、`x = 3.14159`、`m = 1234567` のとき

（1）`佐藤さんは20歳です`  
（2）`3.14`（x を小数点以下2桁で）  
（3）`1,234,567`（m を3桁ごとのカンマ区切りで）  
（4）`[   42]`（42 を5文字分の幅で右寄せ）  

#### 解答例

```text
f'{name}さんは{age}歳です'
f'{x:.2f}'
f'{m:,}'
f'[{42:5}]'
```

#### 解説

`{ }` の中に変数名を書くと、その値が埋め込まれます。先頭の `f` を忘れると `{name}` がそのまま表示されるので注意しましょう。

`{値:書式}` の形で、表示のしかたを指定できます。`.2f` は小数点以下2桁、`,` はカンマ区切り、`5` は5文字分の幅です。

### 問7　（参考）format メソッド

問6の（1）と（2）を、format メソッドを使って書きなさい。

#### 解答例

```python
'{}さんは{}歳です'.format(name, age)
'{:.2f}'.format(x)
```

#### 解説

format メソッドは、`{ }` の場所に、( ) に渡した値が順番に入ります。古いプログラムでよく見かける書き方なので、読めるようにしておきましょう。新しく書くときは f文字列を使います。

### 問8　次のプログラムの問題点を説明し、定数を使って書き直しなさい。

```python
price = int(input('価格：'))
print(price * 1.1)
print(price * 2 * 1.1)
```

#### 解答例

問題点：`1.1` が何を意味するかわかりにくい。税率が変わったときに、何か所も直す必要がある。

**書き直した例**

```python
TAX_RATE = 0.1

price = int(input('価格：'))
print(price * (1 + TAX_RATE))
print(price * 2 * (1 + TAX_RATE))
```

#### 解説

プログラムの途中で変えない値は、名前を大文字にした変数（定数）にしておきます。意味がわかりやすくなり、変更も1か所で済みます。

Python には書き換えを禁止する仕組みはありません。大文字の名前は「変えないでね」という目印です。

名前を入力すると、あいさつを表示するプログラムを作りなさい。

名前：佐藤

### 問10　長方形の面積

縦と横の長さ（整数）を入力すると、長方形の面積と周りの長さを表示するプログラムを作りなさい。

**実行例**

```text
縦：3
横：5
面積は15です
周りの長さは16です
```

#### 解答例

```python
h = int(input('縦：'))
w = int(input('横：'))
print(f'面積は{h * w}です')
print(f'周りの長さは{(h + w) * 2}です')
```

#### 解説

入力した値で計算するときは、`int()` で整数に変換するのを忘れないようにしましょう。

f文字列の `{ }` の中には、`h * w` のような式も書けます。

### 問11　BMI の計算

身長（cm）と体重（kg）を入力すると、BMI を小数点以下1桁で表示するプログラムを作りなさい。BMI ＝ 体重 ÷（身長(m) × 身長(m)）です。小数も入力できるようにしなさい。

**実行例**

```text
身長(cm)：170
体重(kg)：60
BMIは20.8です
```

#### 解答例

```python
height = float(input('身長(cm)：'))
weight = float(input('体重(kg)：'))
bmi = weight / (height / 100) ** 2
print(f'BMIは{bmi:.1f}です')
```

#### 解説

小数も入力できるように `float()` で変換します。

身長は cm なので 100 で割って m にします。`(height / 100) ** 2` のように ( ) を付けないと、計算の順番が変わってしまいます。

`:.1f` で小数点以下1桁に四捨五入して表示しています（変数 bmi の値そのものは変わりません）。

### 問12　（発展）時給の計算

時給と働いた時間（分）を入力すると、給料を表示するプログラムを作りなさい。時給は定数ではなく入力し、給料は1円未満を切り捨てて、3桁ごとのカンマ区切りで表示しなさい。

**実行例**

```text
時給：1100
働いた時間(分)：150
給料は2,750円です
```

#### 解答例

```python
wage = int(input('時給：'))
minutes = int(input('働いた時間(分)：'))
pay = wage * minutes // 60
print(f'給料は{pay:,}円です')
```

#### 解説

分を時間にするために 60 で割ります。`//` を使うと、1円未満が切り捨てられた整数になります。

`wage * minutes / 60` だと float になり、`:,` だけでは `2,750.0` と表示されます。

掛け算を先にしてから割るのがポイントです。`minutes // 60` を先に計算すると、150 // 60 → 2 になり、30分ぶんが消えてしまいます。

## 4-1　while文

### 問1　次のプログラムで、n に 3 を入力したときの表示を答えなさい。

```python
n = int(input('いくつから：'))
while n > 0:
    print(n)
    n -= 1
print('発射！')
```

#### 解答例

```text
3
2
1
発射！
```

#### 解説

| n | n > 0 | 表示 |
| --- | --- | --- |
| 3 | True | 3 |
| 2 | True | 2 |
| 1 | True | 1 |
| 0 | False | （くり返し終了） |

n が 0 になると条件 `n > 0` が成り立たなくなり、くり返しが終わって「発射！」が表示されます。

---

### 問2　次のプログラムは終わりません。理由を説明し、正しく直しなさい。

```python
i = 1
while i <= 5:
    print(i)
```

#### 解答例

理由：i を増やしていないため、i はずっと 1 のままで、条件 `i <= 5` が永遠に成り立つ（無限ループ）。

**直した例**

```python
i = 1
while i <= 5:
    print(i)
    i += 1
```

#### 解説

while文では、くり返しの中で条件に使う変数を必ず変化させます。

回数が決まっているくり返しは、`for i in range(1, 6):` のように for文で書くと、このまちがいを防げます。

### 問3　次のプログラムの表示を答えなさい。

```python
for i in range(1, 10):
    if i % 3 == 0:
        continue
    if i == 7:
        break
    print(i, end=' ')
```

#### 解答例

```text
1 2 4 5 
```

#### 解説

`continue` は残りの処理をとばして次のくり返しへ、`break` はくり返しそのものを終わります。

3 と 6 は `continue` でとばされ、7 で `break` するので、7 以降は表示されません。

### 問4　累算代入演算子

（1）次のプログラムの表示を答えなさい。

```python
x = 2
x *= 3
x -= 1
x //= 2
print(x)
```

（2）次のプログラムの4行目と5行目を、累算代入演算子を使って書き直しなさい。

```python
count = 0
i = 0
while i < 5:
    count = count + 2
    i = i + 1
print(count)
```

#### 解答例

（1）`2`

**（2）**

```python
count = 0
i = 0
while i < 5:
    count += 2
    i += 1
print(count)
```

#### 解説

（1）2 → `x *= 3` で 6 → `x -= 1` で 5 → `x //= 2` で 2 と変わります。

（2）`count = count + 2` は `count += 2`、`i = i + 1` は `i += 1` と書けます。くり返しの中で「数を数える」「合計に足しこむ」ときによく使う形です。

Java や C の `i++` は、Python にはありません。

## 4-2　for文

### 問5　次の range が作る数の並びを答えなさい。

（1）`range(5)`  
（2）`range(1, 6)`  
（3）`range(0, 10, 3)`  
（4）`range(5, 0, -1)`  
（5）`range(10, 0, -3)`  

#### 解答例

（1）0 1 2 3 4　（2）1 2 3 4 5　（3）0 3 6 9　（4）5 4 3 2 1　（5）10 7 4 1

#### 解説

range は「終わりの値を含まない」のがポイントです。1 から 5 までなら `range(1, 6)` と書きます。

増分をマイナスにすると、数が減っていく並びになります。

### 問6　1 から n までの和を求めるつもりのプログラムですが、n に 5 を入力すると 10 と表示されます。理由を説明し、正しく直しなさい。

```python
n = int(input('n：'))
total = 0
for i in range(1, n):
    total += i
print(total)
```

#### 解答例

理由：`range(1, n)` は n を含まないため、1 から 4 までの和（10）になっている。

**直した例**

```python
for i in range(1, n + 1):
```

#### 解説

range の終わりの値を含めたいときは `+ 1` します。よくあるまちがいなので注意しましょう。

### 問7　次のプログラムで、n に 9 と 7 を入力したときの表示をそれぞれ答えなさい。

```python
n = int(input('整数：'))
for i in range(2, n):
    if n % i == 0:
        print('素数ではない')
        break
else:
    print('素数')
```

#### 解答例

9 → `素数ではない`　　7 → `素数`

#### 解説

for文の `else` は、break されずに最後までくり返したときだけ実行されます。

9 は i が 3 のときに割り切れるので break し、else は実行されません。

### 問8　次の while文を、for文と range を使って書き直しなさい。

```python
i = 0
while i < 10:
    print(i)
    i += 2
```

#### 解答例

```python
for i in range(0, 10, 2):
    print(i)
```

#### 解説

0, 2, 4, 6, 8 と 2 ずつ増えるので、range の増分に 2 を指定します。

## 4-3　多重ループ

### 問9　次のプログラムの表示を答えなさい。

**（1）**

```python
for i in range(1, 4):
    for j in range(i):
        print('*', end='')
    print()
```

**（2）**

```python
count = 0
for i in range(3):
    for j in range(4):
        count += 1
print(count)
```

#### 解答例

**（1）**

```text
*
**
***
```

**（2）**

```text
12
```

#### 解説

（1）内側のくり返しの回数が i 回なので、1行目は1個、2行目は2個…と増えていきます。

（2）外側の1回ごとに内側が最後までくり返されるので、3 × 4 ＝ 12 回です。

## 応用問題（プログラムを作る）

### 問10　0 が入力されるまでの合計

整数を次々に入力し、0 が入力されたら、それまでの合計を表示するプログラムを作りなさい。

**実行例**

```text
整数：5
整数：3
整数：0
合計は8です
```

#### 解答例

```python
total = 0
while True:
    x = int(input('整数：'))
    if x == 0:
        break
    total += x
print(f'合計は{total}です')
```

#### 解説

何回くり返すか決まっていないときは、`while True:` と `break` を組み合わせます。

合計用の変数 total は、くり返しの前に 0 で用意します。

### 問11　九九の1つの段

段（1〜9）を入力すると、その段の九九を表示するプログラムを作りなさい。

**実行例**

```text
段：3
3 × 1 = 3
3 × 2 = 6
（中略）
3 × 9 = 27
```

#### 解答例

```python
n = int(input('段：'))
for i in range(1, 10):
    print(f'{n} × {i} = {n * i}')
```

#### 解説

`×` は全角の記号ですが、文字列の中なのでそのまま表示できます。

発展：二重ループにすると、1〜9 の段をすべて表示できます。

### 問12　右寄せの直角三角形

段数を入力すると、右寄せの直角三角形を * で表示するプログラムを作りなさい。

**実行例**

```text
段数：4
   *
  **
 ***
****
```

#### 解答例

```python
n = int(input('段数：'))
for i in range(1, n + 1):
    print(' ' * (n - i) + '*' * i)
```

#### 解説

i 段目は、スペースを n − i 個、* を i 個表示します。

文字列の掛け算 `'*' * i` を使うと、内側のくり返しを書かずに済みます。二重ループで書いてもかまいません。

### 問13　（発展）FizzBuzz

1 から入力した数までを順に表示するプログラムを作りなさい。ただし、3 の倍数のときは「Fizz」、5 の倍数のときは「Buzz」、3 と 5 の両方の倍数のときは「FizzBuzz」と表示しなさい。

#### 解答例

```python
n = int(input('いくつまで：'))
for i in range(1, n + 1):
    if i % 15 == 0:
        print('FizzBuzz')
    elif i % 3 == 0:
        print('Fizz')
    elif i % 5 == 0:
        print('Buzz')
    else:
        print(i)
```

#### 解説

15 の倍数（3 と 5 の両方の倍数）の判定を最初に書くのがポイントです。`i % 3 == 0` を先に書くと、15 でも「Fizz」になってしまいます（第3章の条件の順番と同じ）。

プログラミングの面接試験でもよく出される、有名な問題です。

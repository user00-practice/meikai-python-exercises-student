## 1-1　Pythonとは

### 問1　Python について、（　）に当てはまる言葉を答えなさい。

（1）Python は、記号が少なく英文に近い書き方ができるため、（　①　）言語だといわれる。  
（2）Python 2 と Python 3 には（　②　）がないため、この授業では Python（　③　）を使う。  
（3）プログラムを1行ずつ入力して、すぐに結果を確かめられる仕組みを（　④　）という。  

#### 解答例

① 読みやすい　② 互換性　③ 3　④ インタラクティブシェル（対話モード）

#### 解説

Python 2 は 2020年1月にサポートが終了しています。インターネットで古い記事（`print` に ( ) がない書き方など）を見つけたら、Python 2 向けの可能性があるので注意しましょう。

### 問2　プログラムの実行方法

Python のプログラムを動かす2つの方法「スクリプト実行」と「インタラクティブシェル」の違いを、それぞれ1文で説明しなさい。

#### 解答例

スクリプト実行：プログラムをファイル（拡張子 `.py`）に書いて保存し、まとめて実行する方法。

インタラクティブシェル：`>>>` のあとに1行ずつ入力し、その場で結果を確かめる方法。

#### 解説

インタラクティブシェルは電卓のように手軽に試せるので、第1章の内容を確かめるのに向いています。長いプログラムや何度も使うプログラムはファイルに保存します。

## 1-2　Pythonの基本

### 問3　次の式の結果を答えなさい。

|   | 式 |   | 式 |
| --- | --- | --- | --- |
| （1） | `7 + 2 * 3` | （2） | `(7 + 2) * 3` |
| （3） | `7 / 2` | （4） | `7 // 2` |
| （5） | `7 % 2` | （6） | `2 ** 4` |
| （7） | `6 / 3` | （8） | `10 - 4 - 3` |

#### 解答例

|   | 結果 |   | 結果 |
| --- | --- | --- | --- |
| （1） | `13` | （2） | `27` |
| （3） | `3.5` | （4） | `3` |
| （5） | `1` | （6） | `16` |
| （7） | `2.0` | （8） | `3` |

#### 解説

（1）（2）掛け算 `*` は足し算 `+` より先に計算されます。先に計算したい部分は ( ) で囲みます。

（3）（7）`/` の結果は、割り切れても必ず小数（float）になります。`6 / 3` は `2` ではなく `2.0` です。

（4）（5）`//` は割り算の商、`%` は割り算のあまりです（7 ÷ 2 ＝ 3 あまり 1）。

（8）同じ優先順位の演算子は左から順に計算されます：(10 − 4) − 3 ＝ 3。

### 問4　次の値の型（int・float・str のどれか）を答えなさい。

（1）`10`  
（2）`10.0`  
（3）`'10'`  
（4）`7 / 7`  
（5）`7 // 7`  
（6）`3 + 2.0`  

#### 解答例

（1）int　（2）float　（3）str　（4）float　（5）int　（6）float

#### 解説

（3）は ' で囲まれているので、数字に見えても文字列です。

（4）`/` の結果は常に float です。（5）`//` は整数どうしなら int になります。

（6）int と float を計算すると、結果は float になります。

型は `type(10)` のように `type()` で確かめられます。

### 問5　次のプログラムを実行したときの表示を答えなさい。

（1）`print('A\nB')`  
（2）`print('C:\\temp')`  
（3）`print('It\'s')`  

#### 解答例

**（1）**

```text
A
B
```

**（2）**

```text
C:\temp
```

**（3）**

```text
It's
```

#### 解説

`\n` は改行、`\\` は `\` そのもの、`\'` は `'` そのものを表すエスケープシーケンスです。

（3）は `"It's"` のように `"` で囲む書き方でも同じ結果になります。

日本語の Windows では `\` が `¥` と表示されることがありますが、同じ文字です。

### 問7　次のプログラムを順に実行したとき、最後の変数の値を答えなさい。

**（1）最後の x の値**

```python
x = 5
x = x + 3
x = x * 2
```

**（2）最後の a と b の値**

```python
a, b = 1, 2
a, b = b, a
```

**（3）最後の x の値**

```python
x = 10
x += 5
x *= 2
```

#### 解答例

（1）`16`　（2）`a` は `2`、`b` は `1`　（3）`30`

#### 解説

| 行 | x の値 |
| --- | --- |
| `x = 5` | 5 |
| `x = x + 3` | 5 + 3 → 8 |
| `x = x * 2` | 8 × 2 → 16 |

`=` は「等しい」ではなく「右辺を計算して左辺の変数に入れる」という意味です。右から左に読みます。

（2）`a, b = b, a` は2つの変数の値を入れ替える Python ならではの書き方です。

（3）`x += 5` は `x = x + 5` と同じ意味です。10 → 15 → 30。

### 問8　次のうち、変数名として使えるものに ○、使えないものに × を付けなさい。

|   | 変数名 | ○／× |   | 変数名 | ○／× |
| --- | --- | --- | --- | --- | --- |
| （1） | `score` |   | （2） | `2nd_name` |   |
| （3） | `my_name` |   | （4） | `for` |   |
| （5） | `_total` |   | （6） | `my-name` |   |

#### 解答例

（1）○　（2）×　（3）○　（4）×　（5）○　（6）×

#### 解説

（2）数字で始まる名前は使えません。

（4）`for` は Python が使う予約語（キーワード）なので使えません。

（6）`-` は引き算の演算子と区別できないので使えません。単語をつなぐときは `_` を使います。

### 問9　次のうち「式」はどれですか。すべて選びなさい。

（1）`3 + 4`  
（2）`x = 3 + 4`  
（3）`'Python'`  
（4）`x * 2`  

#### 解答例

（1）（3）（4）

#### 解説

式は、計算すると値になるものです。シェルで入力すると値が表示されます。

（2）は代入「文」です。その中の `3 + 4` の部分は式です。シェルで入力しても何も表示されません。

### 問10　次のプログラムにはまちがいがあります。エラーになる理由と、正しい書き方を答えなさい。

**（1）**

```python
x = 10
y = X + 1
```

**（2）**

```python
print('Python")
```

#### 解答例

（1）変数名の大文字と小文字は区別されるため、`X` は定義されていない（NameError）。正しくは `y = x + 1`。

（2）文字列を `'` で始めて `"` で閉じているため、文字列が終わっていない（SyntaxError）。正しくは `print('Python')`。

#### 解説

エラーメッセージの最後の行（`NameError: name 'X' is not defined` など）に、エラーの種類と原因が書かれています。まずそこを読む習慣をつけましょう。

## 応用問題

### 問11　インタラクティブシェルで計算しなさい。

（1）1日は何秒ですか。計算する式と結果を答えなさい。  
（2）100円の商品を3個と、250円の商品を2個買いました。合計金額と、1000円を払ったときのおつりを計算する式と結果を答えなさい。  
（3）125分は何時間何分ですか。`//` と `%` を使って計算しなさい。  

#### 解答例

**（1）**

```python
>>> 24 * 60 * 60
86400
```

**（2）**

```python
>>> 100 * 3 + 250 * 2
800
>>> 1000 - (100 * 3 + 250 * 2)
200
```

**（3）2時間5分**

```python
>>> 125 // 60
2
>>> 125 % 60
5
```

#### 解説

（2）おつりの式では ( ) を忘れると `1000 - 100 * 3 + 250 * 2` となり、1200 になってしまいます。

（3）時間は 60 で割った商、分はあまりです。秒を「分と秒」にするときも同じ考え方が使えます。

変数を使って `total = 100 * 3 + 250 * 2`、`change = 1000 - total` と書くと、わかりやすくなります。

### 問12　（発展）マイナスの数の割り算

次の式の結果を予想し、インタラクティブシェルで確かめなさい。予想と違った場合は、その理由を考えなさい。

（1）`-7 // 2`  
（2）`-7 % 2`  

#### 解答例

（1）`-4`　（2）`1`

#### 解説

−7 ÷ 2 ＝ −3.5 を、Python の `//` は数直線の小さい方（−4）に切り捨てます。そのため、あまりは −7 − (−4 × 2) ＝ 1 になります。

Java や C 言語では 0 に近い方（−3）に切り捨てるため、あまりは −1 になります。くわしくは補足スライド「負の数と % 演算子」を参照してください。

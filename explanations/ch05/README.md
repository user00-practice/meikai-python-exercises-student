## 5-1　オブジェクト

### 問1　次のプログラムを実行したとき、最後の print の表示を答えなさい。

**（1）**

```python
x = 10
y = x
x += 1
print(y)
```

**（2）**

```python
a = [1, 2]
b = a
b.append(3)
print(a)
```

#### 解答例

（1）`10`　（2）`[1, 2, 3]`

#### 解説

`y = x` や `b = a` は、値のコピーではなく、同じオブジェクトに名札を追加しているだけです。

（1）int はイミュータブル（変更できない）なので、`x += 1` では新しいオブジェクト 11 が作られ、x の名札だけが付け替えられます。y は 10 のままです。

（2）リストはミュータブル（変更できる）なので、b を通して変更すると、同じリストに付いている a から見ても変わっています。

### 問2　次の型を、ミュータブル（変更できる）とイミュータブル（変更できない）に分けなさい。

int　float　str　list　tuple　dict　set

#### 解答例

ミュータブル：list　dict　set

イミュータブル：int　float　str　tuple

#### 解説

文字列（str）もイミュータブルです。第6章で学ぶ replace などのメソッドは、元の文字列を変えずに新しい文字列を返します。

### 問3　次の式の結果（True または False）を答えなさい。

```python
a = [1, 2]
b = [1, 2]
c = a
```

（1）`a == b`  
（2）`a is b`  
（3）`a is c`  
（4）`a is not b`  

#### 解答例

（1）True　（2）False　（3）True　（4）True

#### 解説

`==` は値が等しいか、`is` は同じオブジェクトかを調べます。a と b は同じ値ですが、別々に作られた別のオブジェクトです。

値を比べるときは `==` を使い、`is` は `x is None` のように None の判定に使うのが基本です。

### 問4　次のプログラムの表示を答えなさい。

```python
r = print('A')
print(r)
x = None
print(x is None)
```

#### 解答例

```text
A
None
True
```

#### 解説

print は画面に表示するだけで、値を返しません。値を返さない関数の結果は `None` になります。

None かどうかは `is` で調べます。

### 問5　（代入式）次の式の結果を答えなさい。

```python
>>> (x := 10) + 5
>>> x
```

#### 解答例

`(x := 10) + 5` の結果は `15`、そのあとの `x` の値は `10`

#### 解説

`:=` は代入しながら、その値を式の中で使える「代入式」です。x に 10 を入れ、その 10 に 5 を足した 15 が式の結果になります。

### 問6　次の式の結果と型を答えなさい。

|   | 式 |   | 式 |
| --- | --- | --- | --- |
| （1） | `True + True` | （2） | `True * 10` |
| （3） | `1 + 2.0` | （4） | `7 // 2` |
| （5） | `7.5 // 2` | （6） | `(3 + 4j).imag` |

#### 解答例

（1）2（int）　（2）10（int）　（3）3.0（float）　（4）3（int）　（5）3.0（float）　（6）4.0（float）

（6）`.imag` は複素数の虚部です。複素数の実部・虚部は float になります。

### 問7　浮動小数点数の誤差

次のプログラムの表示を答え、なぜそうなるか説明しなさい。また、2つの小数が「ほぼ等しい」かを正しく調べる方法を答えなさい。

```python
print(0.1 + 0.2 == 0.3)
```

#### 解答例

表示：`False`

理由：コンピュータは小数を2進数で表すため、0.1 などを正確に表せず、`0.1 + 0.2` が `0.30000000000000004` になるから。

**正しく調べる方法**

```python
import math
print(math.isclose(0.1 + 0.2, 0.3))   # True
```

#### 解説

小数どうしを `==` で比べるのは危険です。表示を整えるだけなら `round()` や f文字列の `:.2f` を使います。

### 問8　次のビット演算の結果を答えなさい。

（1）`bin(13)`  
（2）`12 & 10`  
（3）`12 | 10`  
（4）`12 ^ 10`  
（5）`5 << 2`  
（6）`20 >> 2`  

#### 解答例

（1）`'0b1101'`　（2）`8`　（3）`14`　（4）`6`　（5）`20`　（6）`5`

#### 解説

|   | 2進数 | 10進数 |
| --- | --- | --- |
| 12 | 1100 | 12 |
| 10 | 1010 | 10 |
| 12 & 10 | 1000 | 8（両方 1） |
| 12 \| 10 | 1110 | 14（どちらか 1） |
| 12 ^ 10 | 0110 | 6（ちがえば 1） |

`<<` は左に1つずらすごとに2倍、`>>` は右に1つずらすごとに2で割った商になります。

## 応用問題（プログラムを作る）

### 問9　いろいろな進数で表示

整数を入力すると、2進数・8進数・16進数で表示するプログラムを作りなさい。

**実行例**

```text
整数：255
2進数：0b11111111
8進数：0o377
16進数：0xff
```

#### 解答例

```python
n = int(input('整数：'))
print(f'2進数：{bin(n)}')
print(f'8進数：{oct(n)}')
print(f'16進数：{hex(n)}')
```

#### 解説

`bin()`・`oct()`・`hex()` は、整数を2進数・8進数・16進数の文字列に変換する組込み関数です。

f文字列の書式指定 `{n:b}`・`{n:o}`・`{n:x}` を使うと、先頭の 0b などを付けずに表示できます。

### 問10　（発展）ビット演算で偶数・奇数を判定

`%` を使わずに、ビット演算子 `&` を使って、入力した整数が偶数か奇数かを判定するプログラムを作りなさい。

**実行例**

```text
整数：7
奇数です
```

#### 解答例

```python
n = int(input('整数：'))
if n & 1 == 0:
    print('偶数です')
else:
    print('奇数です')
```

#### 解説

2進数のいちばん右のけた（1 の位）が 0 なら偶数、1 なら奇数です。`n & 1` でいちばん右のけただけを取り出せます。

ふだんは読みやすい `n % 2 == 0` を使えば十分です。

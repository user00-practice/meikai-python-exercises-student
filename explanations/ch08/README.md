## 8-1　タプル

### 問1　次の式の結果を答えなさい。エラーになる場合は、エラーの種類を答えなさい。

（1）`type((5))`  
（2）`type((5,))`  
（3）`t = (1, 2, 3)` のあとの `t[0] = 9`  
（4）`(1, 2) + (3,)`  
（5）`tuple('abc')`  

#### 解答例

（1）`<class 'int'>`　（2）`<class 'tuple'>`　（3）TypeError　（4）`(1, 2, 3)`　（5）`('a', 'b', 'c')`

#### 解説

（1）`(5)` はただの 5（計算の優先順位のかっこ）です。要素が1つのタプルは `(5,)` とカンマが必要です。

（3）タプルはイミュータブルなので、要素を書き換えられません。

---

### 問2　次のプログラムの表示を答えなさい。

```python
names = ['佐藤', '鈴木', '高橋']
scores = [80, 65, 90]
for n, s in zip(names, scores):
    print(n, s)
print(list(enumerate(names)))
```

#### 解答例

```text
佐藤 80
鈴木 65
高橋 90
[(0, '佐藤'), (1, '鈴木'), (2, '高橋')]
```

#### 解説

zip は同じ位置の要素を組にしたタプルを作り、`n, s` にアンパックしています。

enumerate も (番号, 要素) のタプルを作っています。

## 8-2　辞書

### 問3　`d = {'apple': 100, 'banana': 80}` のとき、次の式の結果を答えなさい。エラーになる場合は、エラーの種類を答えなさい。

（1）`d['apple']`  
（2）`d['kiwi']`  
（3）`d.get('kiwi')`  
（4）`d.get('kiwi', 0)`  
（5）`'apple' in d`  
（6）`100 in d`  
（7）`len(d)`  

#### 解答例

（1）`100`　（2）KeyError　（3）`None`　（4）`0`　（5）`True`　（6）`False`　（7）`2`

#### 解説

キーがあるかわからないときは get を使うと、エラーにならずに済みます。

（6）`in` が調べるのはキーです。値 100 があっても False になります。値を調べるなら `100 in d.values()` です。

### 問4　次のプログラムを順に実行したとき、最後の d の値を答えなさい。

```python
d = {}
d['a'] = 1
d['b'] = 2
d['a'] = 3
d.setdefault('c', 4)
d.setdefault('a', 9)
del d['b']
print(d)
```

#### 解答例

`{'a': 3, 'c': 4}`

#### 解説

`d['a'] = 3` は、キー 'a' がすでにあるので上書きです。

setdefault は、キーがなければ追加し、あれば何もしません（'a' は 3 のまま）。

### 問5　次のプログラムの表示を答えなさい。

```python
price = {'りんご': 100, 'みかん': 80}
for k, v in price.items():
    print(f'{k}は{v}円')
print({x: x * x for x in range(1, 4)})
```

#### 解答例

```text
りんごは100円
みかんは80円
{1: 1, 2: 4, 3: 9}
```

#### 解説

`items()` は (キー, 値) のタプルを順に作ります。辞書は追加した順番を覚えています。

最後の行は辞書内包表記です。

## 8-3　集合

### 問6　`A = {1, 2, 3}`、`B = {2, 3, 4}` のとき、次の式の結果を答えなさい。

（1）`A | B`  
（2）`A & B`  
（3）`A - B`  
（4）`A ^ B`  
（5）`len(set('hello'))`  
（6）`type({})`  

#### 解答例

（1）`{1, 2, 3, 4}`　（2）`{2, 3}`　（3）`{1}`　（4）`{1, 4}`　（5）`4`　（6）`<class 'dict'>`

#### 解説

（5）集合は重複を許さないので、'hello' の 'l' は1つにまとまり、{'h', 'e', 'l', 'o'} の4個になります。

（6）`{}` は空の辞書です。空の集合は `set()` と書きます。

### 問7　次のデータをまとめるのに最も適した型（list・tuple・dict・set）を答えなさい。

（1）クラス全員の点数を、入力した順に記録する  
（2）商品名から価格を調べられるようにする  
（3）日付（年, 月, 日）のように、変えてはいけない値の組  
（4）アンケートで回答した人の名前を、重複なしで集める  

#### 解答例

（1）list　（2）dict　（3）tuple　（4）set

#### 解説

「順番に並べる・あとで変更する」→ list、「キーで値を引く」→ dict、「変更しない組」→ tuple、「重複なし・含まれるかを調べる」→ set、と使い分けます。

## 応用問題（プログラムを作る）

### 問8　単語の出現回数

スペース区切りで単語を入力すると、それぞれの単語が何回出てきたかを表示するプログラムを作りなさい。

**実行例**

```text
単語をスペース区切りで：りんご みかん りんご ぶどう りんご
りんご：3回
みかん：1回
ぶどう：1回
```

#### 解答例

```python
text = input('単語をスペース区切りで：')
count = {}
for w in text.split():
    count[w] = count.get(w, 0) + 1
for w, c in count.items():
    print(f'{w}：{c}回')
```

#### 解説

`count.get(w, 0) + 1` は「まだなければ 0、あれば今の回数」に 1 を足します。辞書を使った集計の定番です。

### 問9　価格の検索

次の辞書を使い、品名を入力すると価格を表示するプログラムを作りなさい。辞書にない品名のときは「〇〇は扱っていません」と表示しなさい。

```python
PRICES = {'りんご': 100, 'みかん': 80, 'ぶどう': 300}
```

**実行例**

```text
品名：メロン
メロンは扱っていません
```

#### 解答例

```python
PRICES = {'りんご': 100, 'みかん': 80, 'ぶどう': 300}
name = input('品名：')
if name in PRICES:
    print(f'{name}は{PRICES[name]}円です')
else:
    print(f'{name}は扱っていません')
```

#### 解説

先に `in` でキーがあるか調べてから `PRICES[name]` で取り出します。`PRICES.get(name)` の結果が None かどうかで判定してもかまいません。

### 問10　（発展）両方に参加した人

イベントAとイベントBの参加者の名前を、それぞれスペース区切りで入力します。両方に参加した人・どちらかに参加した人・Aだけに参加した人を表示するプログラムを作りなさい。表示は sorted で並べなさい。

**実行例**

```text
Aの参加者：佐藤 鈴木 高橋
Bの参加者：鈴木 田中 佐藤
両方：['佐藤', '鈴木']
どちらか：['佐藤', '田中', '鈴木', '高橋']
Aだけ：['高橋']
```

#### 解答例

```python
a = set(input('Aの参加者：').split())
b = set(input('Bの参加者：').split())
print(f'両方：{sorted(a & b)}')
print(f'どちらか：{sorted(a | b)}')
print(f'Aだけ：{sorted(a - b)}')
```

#### 解説

集合は順番がないので、表示するときは sorted でリストにして並べています。

漢字の sorted は文字コードの順になるため、五十音順にはなりません。

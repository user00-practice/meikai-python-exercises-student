## 3-1　if文

### 問1　次の式の結果（True または False）を答えなさい。

|   | 式 |   | 式 |
| --- | --- | --- | --- |
| （1） | `3 < 5` | （2） | `5 >= 5` |
| （3） | `3 != 3` | （4） | `'abc' == 'abc'` |
| （5） | `0 <= 7 <= 10` | （6） | `7 in {1, 3, 7}` |

#### 解答例

（1）True　（2）True　（3）False　（4）True　（5）True　（6）True

#### 解説

（2）`>=` は「以上」なので、等しいときも True です。

（5）`0 <= 7 <= 10` は `0 <= 7 and 7 <= 10` と同じ意味です。Python では数学と同じように比較をつなげて書けます。

（6）`in` は、値が集合の中のどれかと等しいかを調べます。

### 問2　論理演算子と bool

次の式の結果（True または False）を答えなさい。

（1）`3 > 1 and 2 > 5`  
（2）`3 > 1 or 2 > 5`  
（3）`not 3 > 1`  
（4）`bool(0)`  
（5）`bool('')`  
（6）`bool('0')`  

#### 解答例

（1）False　（2）True　（3）False　（4）False　（5）False　（6）True

#### 解説

`and` は両方が成り立つとき、`or` はどちらかが成り立つときに True です。`not` は反対にします。

（4）〜（6）0 や空の文字列 `''` は「偽」として扱われます。（6）の `'0'` は空ではない文字列なので「真」です。

### 問3　次のプログラムで、n に 5、0、-3 を入力したときの表示をそれぞれ答えなさい。

```python
n = int(input('整数：'))
if n > 0:
    print('正')
elif n == 0:
    print('ゼロ')
else:
    print('負')
```

#### 解答例

5 → `正`　0 → `ゼロ`　-3 → `負`

#### 解説

条件は上から順に調べられ、最初に成り立ったところだけが実行されます。どれも成り立たなければ `else` が実行されます。

### 問4　次のプログラムは、点数が 80 以上なら「優秀」、60 以上なら「合格」、それ以外は「不合格」と表示するつもりですが、正しく動きません。理由を説明し、正しく直しなさい。

```python
score = int(input('点数：'))
if score >= 60:
    print('合格')
elif score >= 80:
    print('優秀')
else:
    print('不合格')
```

#### 解答例

理由：85点のように 80 以上の点数も、先に `score >= 60` が成り立つため「合格」になってしまう。`elif score >= 80:` は実行されることがない。

**直した例**

```python
if score >= 80:
    print('優秀')
elif score >= 60:
    print('合格')
else:
    print('不合格')
```

#### 解説

elif を使うときは、条件の順番が大切です。範囲がせまい（きびしい）条件から先に書きます。

### 問5　次のプログラムはエラーになります。それぞれの理由と、正しい書き方を答えなさい。

**（1）**

```python
if n > 0
    print(n)
```

**（2）**

```python
if n = 5:
    print(n)
```

**（3）**

```python
if n > 0:
print(n)
```

#### 解答例

（1）条件のあとのコロン（:）がない（SyntaxError）。正しくは `if n > 0:`。

（2）`=` は代入。等しいかを調べるには `==` を使う（SyntaxError）。正しくは `if n == 5:`。

（3）`print(n)` が字下げされていない（IndentationError）。正しくはスペース4つで字下げする。

#### 解説

どれも if文で最もよくある間違いです。エラーメッセージにもヒントが表示されます（（1）`expected ':'`、（2）`Maybe you meant '=='`、（3）`expected an indented block`）。

### 問6　次のプログラムを、条件演算子を使って書き直しなさい。

```python
if n % 2 == 0:
    s = '偶数'
else:
    s = '奇数'
```

#### 解答例

```python
s = '偶数' if n % 2 == 0 else '奇数'
```

#### 解説

`値1 if 条件 else 値2` は、条件が成り立てば値1、成り立たなければ値2 になる「式」です。代入や print の中に直接書けます。

## 3-2　入れ子のif文とスイート

### 問7　次のプログラムで、a に 8、b に 5、c に 2 を入力したとき、各 if文を実行したあとの a・b・c の値を答えなさい。

```python
if a > b:
    a, b = b, a    # ①
if b > c:
    b, c = c, b    # ②
if a > b:
    a, b = b, a    # ③
print(a, b, c)
```

|   | a | b | c |
| --- | --- | --- | --- |
| 入力 | 8 | 5 | 2 |
| ①のあと |   |   |   |
| ②のあと |   |   |   |
| ③のあと |   |   |   |

#### 解答例

|   | a | b | c |
| --- | --- | --- | --- |
| 入力 | 8 | 5 | 2 |
| ①のあと | 5 | 8 | 2 |
| ②のあと | 5 | 2 | 8 |
| ③のあと | 2 | 5 | 8 |

表示は `2 5 8`（小さい順に並ぶ）

#### 解説

隣どうしを比べて、大きい方を後ろに入れ替えることを3回くり返すと、3つの値が小さい順に並びます。

同じことは `a, b, c = sorted([a, b, c])` でもできます。

### 問8　次のプログラムで、表示されるのはどれですか。n が 7 のときと -4 のときについて答えなさい。

```python
if n > 0:
    if n % 2 == 0:
        print('A')
    else:
        print('B')
else:
    print('C')
print('D')
```

#### 解答例

n が 7 のとき：`B` と `D`　　n が -4 のとき：`C` と `D`

#### 解説

内側の if文は、外側の `n > 0` が成り立ったときだけ調べられます。

`print('D')` は if文の外（字下げなし）なので、どの場合も必ず実行されます。

## 3-3　プログラムの構成要素

### 問9　次の文の各部分（①〜⑤）が、キーワード・識別子・演算子・リテラル・区切り子のどれにあたるか答えなさい。

```python
if price >= 1000:
```

| ① | ② | ③ | ④ | ⑤ |
| --- | --- | --- | --- | --- |
| `if` | `price` | `>=` | `1000` | `:` |

#### 解答例

① キーワード　② 識別子　③ 演算子　④ リテラル　⑤ 区切り子

#### 解説

`if` は Python が意味を決めている単語（キーワード）、`price` は自分で付けた名前（識別子）、`1000` は直接書いた値（リテラル）です。

---

### 問10　構文エラーと例外の違いを、それぞれ例を挙げて説明しなさい。

#### 解答例

構文エラー：文法のまちがい。実行する前に見つかり、プログラムは1行も実行されない。例：`if n > 0`（コロンがない）。

例外：文法は正しいが、実行中に起きる問題。その行で止まる。例：`10 / 0`（ZeroDivisionError）、`int('abc')`（ValueError）。

#### 解説

例外への対処（try / except）は第12章で学びます。

## 応用問題（プログラムを作る）

### 問11　入場料の計算

年齢を入力すると入場料を表示するプログラムを作りなさい。6歳未満は無料、65歳以上は500円、それ以外は1000円です。

**実行例**

```text
年齢：30
入場料は1000円です
```

#### 解答例

```python
age = int(input('年齢：'))
if age < 6:
    fee = 0
elif age >= 65:
    fee = 500
else:
    fee = 1000
print(f'入場料は{fee}円です')
```

#### 解説

料金を変数 `fee` に入れておき、最後に1回だけ表示すると、表示の文を何度も書かずに済みます。

5歳・6歳・64歳・65歳のような「境目」の値で試して、正しく分かれるか確かめましょう。

### 問12　（発展）うるう年の判定

西暦を入力すると、うるう年かどうかを表示するプログラムを作りなさい。うるう年は「4で割り切れる年。ただし100で割り切れる年はうるう年ではない。ただし400で割り切れる年はうるう年」です。2000年・1900年・2024年・2023年で確かめなさい。

**実行例**

```text
西暦：2024
うるう年です
```

#### 解答例

```python
year = int(input('西暦：'))
if (year % 4 == 0 and year % 100 != 0) or year % 400 == 0:
    print('うるう年です')
else:
    print('うるう年ではありません')
```

2000年 → うるう年、1900年 → うるう年ではない、2024年 → うるう年、2023年 → うるう年ではない

#### 解説

「割り切れる」は `% 〇 == 0`、「割り切れない」は `% 〇 != 0` で表します。

`and` と `or` を組み合わせるときは、( ) で囲んで意味をはっきりさせましょう。

入れ子の if文で書くこともできます。いろいろな書き方を試してみましょう。

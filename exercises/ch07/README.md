# 第7章　リスト　練習問題

[← 目次に戻る](../../README.md)　／　[解答例・解説](../../explanations/ch07/README.md)

リストはミュータブル（変更できる）なので、「リスト自体が変わる操作」と「新しいリストを作る操作」の区別が大切です。コピーの問題は、名札の図を描いて考えましょう。

> 📝 マークの問題は、このフォルダの .py ファイルにプログラムを書きます。書けたら、プロジェクトのフォルダで `python tools/check.py ch07` を実行してチェックしましょう。

## 7-1　リスト

### 問1　`a = [10, 20, 30, 40, 50]` のとき、次の式の結果を答えなさい。

|   | 式 |   | 式 |
| --- | --- | --- | --- |
| （1） | `a[1]` | （2） | `a[-2]` |
| （3） | `a[1:3]` | （4） | `a[::-1]` |
| （5） | `len(a)` | （6） | `sum(a) / len(a)` |
| （7） | `30 in a` | （8） | `a.index(40)` |

---

### 問2　次のプログラムを順に実行したとき、最後の a の値を答えなさい。

```python
a = [1, 2, 3]
a.append(4)
a.insert(0, 0)
a.pop()
a.remove(2)
print(a)
```

---

### 問3　次のプログラムの表示を答えなさい。

```python
a = [1, 2]
a.append([3, 4])
print(a)
b = [1, 2]
b.extend([3, 4])
print(b)
```

---

### 問4　次のプログラムの表示を答えなさい。

```python
a = [1, 2]
b = a
b[0] = 99
c = a.copy()
c[1] = 0
print(a, b, c)
```

---

### 問5　次のプログラムは、並べ替えたリストを表示するつもりですが「None」と表示されます。理由を説明し、2通りの方法で直しなさい。

```python
a = [3, 1, 2]
b = a.sort()
print(b)
```

---

### 問6　`m = [[1, 2, 3], [4, 5, 6]]` のとき、次の式の結果を答えなさい。

（1）`m[1][0]`  
（2）`m[0][2]`  
（3）`len(m)`  
（4）`len(m[0])`  
（5）`m[1]`

## 7-2　リスト内包表記

### 問7　次のリスト内包表記の結果を答えなさい。

（1）`[x * 2 for x in range(4)]`  
（2）`[x for x in range(10) if x % 3 == 0]`  
（3）`[len(w) for w in ['a', 'bb', 'ccc']]`  
（4）`[c.upper() for c in 'abc']`  

---

### 問8　次のプログラムの表示を答え、そうなる理由と正しい2次元リストの作り方を答えなさい。

```python
g = [[0] * 2] * 2
g[0][0] = 1
print(g)
```

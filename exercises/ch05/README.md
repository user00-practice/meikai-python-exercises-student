## 5-1　オブジェクト

### 問1　次のプログラムを実行したとき、最後の print の表示を答えなさい。

**（1）**

```python
x = 10
y = x
x += 1
print(y)
```

**（2）**

```python
a = [1, 2]
b = a
b.append(3)
print(a)
```


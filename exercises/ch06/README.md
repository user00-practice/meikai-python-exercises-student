## 6-1　文字列の基礎

### 問1　`s = 'Python'` のとき、次の式の結果を答えなさい。

|   | 式 |   | 式 |
| --- | --- | --- | --- |
| （1） | `s[0]` | （2） | `s[-1]` |
| （3） | `s[1:4]` | （4） | `s[:2]` |
| （5） | `s[::-1]` | （6） | `s[::2]` |
| （7） | `len(s)` | （8） | `s[1:100]` |

---

### 問2　次のプログラムはエラーになります。理由を答えなさい。また（2）は、'Jython' という文字列を作る正しい方法を答えなさい。

**（1）**

```python
s = 'Python'
print(s[6])
```

**（2）**

```python
s = 'Python'
s[0] = 'J'
```

---

### 問3　次の式の結果（True または False）を答えなさい。

（1）`'abc' < 'abd'`  
（2）`'A' < 'a'`  
（3）`'10' < '9'`  
（4）`'th' in 'Python'`  
（5）`'z' not in 'Python'`  

---

### 問4　次のプログラムの表示を答えなさい。

```python
for i, c in enumerate('abc', 1):
    print(f'{i}番目：{c}')
```

## 6-2　文字列の操作

（5）`s.replace('a', 'o')`  
（6）`s.upper()`  
（7）`s.startswith('ba')`  

---

### 問6　次のプログラムは「bonono」と表示するつもりですが、「banana」と表示されます。理由を説明し、正しく直しなさい。

```python
s = 'banana'
s.replace('a', 'o')
print(s)
```

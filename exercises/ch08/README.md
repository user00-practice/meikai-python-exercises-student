### 問2　次のプログラムの表示を答えなさい。

```python
names = ['佐藤', '鈴木', '高橋']
scores = [80, 65, 90]
for n, s in zip(names, scores):
    print(n, s)
print(list(enumerate(names)))
```

（2）`d['kiwi']`  
（3）`d.get('kiwi')`  
（4）`d.get('kiwi', 0)`

### 問4　次のプログラムを順に実行したとき、最後の d の値を答えなさい。

```python
d = {}
d['a'] = 1
d['b'] = 2
d['a'] = 3
d.setdefault('c', 4)
d.setdefault('a', 9)
del d['b']
print(d)
```

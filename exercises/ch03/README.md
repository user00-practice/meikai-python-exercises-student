### 問3　次のプログラムで、n に 5、0、-3 を入力したときの表示をそれぞれ答えなさい。

```python

    print('正')
elif n == 0:
    print('ゼロ')
else:
    print('負')
```

### 問4　次のプログラムは、点数が 80 以上なら「優秀」、60 以上なら「合格」、それ以外は「不合格」と表示するつもりですが、正しく動きません。理由を説明し、正しく直しなさい。

    print('合格')

## 3-2　入れ子のif文とスイート

### 問7　次のプログラムで、a に 8、b に 5、c に 2 を入力したとき、各 if文を実行したあとの a・b・c の値を答えなさい。

```python
if a > b:
    a, b = b, a    # ①
if b > c:
    b, c = c, b    # ②
if a > b:
    a, b = b, a    # ③
print(a, b, c)
```

|   | a | b | c |
| --- | --- | --- | --- |
| 入力 | 8 | 5 | 2 |
| ①のあと |   |   |   |
| ②のあと |   |   |   |
| ③のあと |   |   |   |

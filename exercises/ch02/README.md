## 2-2　キーボードからの読込み

### 問4　次のプログラムで、a に 10、b に 20 を入力したときの表示を答えなさい。

**（1）**

```python
a = input('a：')
b = input('b：')
print(a + b)
```

**（2）**

```python
a = int(input('a：'))
b = int(input('b：'))
print(a + b)
```

---

### 問11　BMI の計算

身長（cm）と体重（kg）を入力すると、BMI を小数点以下1桁で表示するプログラムを作りなさい。BMI ＝ 体重 ÷（身長(m) × 身長(m)）です。小数も入力できるようにしなさい。

**実行例**

```text
身長(cm)：170
体重(kg)：60
BMIは20.8です
```
